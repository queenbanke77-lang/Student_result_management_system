# Student Result Management System

A Python-based command-line application designed for secondary schools and educational centers to manage student records, record subject scores, compute academic standings, and generate persistent reports.

## Features
- **Student Management**: Add, view, search, update, and delete student records.
- **Score & Result Management**: Record subject scores across 5 core subjects, compute totals, averages, and assign letter grades (A-F).
- **Reporting & Analysis**: Sort students by name or average performance, view class statistics (highest, lowest, and class averages), and export formatted text reports.
- **Data Persistence**: Automatically stores and loads data using JSON files.
